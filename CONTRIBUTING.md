# Contributing

- Run the tests before submitting changes:

  ```bash
  .venv/bin/python -m pytest tests/ -q
  ```

- Use conventional commit style, e.g. `feat: add release gate check` or `fix: correct audit log ordering`.
- All contributions are accepted under the project license ([PolyForm Noncommercial 1.0.0](LICENSE)).
- Open an issue before starting large changes.
